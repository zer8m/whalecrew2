# 웨일 스토어 등록 자료

기준: [웨일 개발자센터 스토어 등록](https://whale.dev/distribution/) · [업데이트](https://whale.dev/distribution/update/) · [심사 가이드](https://developers.whale.naver.com/review_guides/)

## 1. 준비 파일 (이 폴더)
| 항목 | 규격 | 파일 |
|---|---|---|
| 확장앱 패키지 | ZIP, `manifest.json`이 zip 최상위 | `attchacha-1.0.6.zip` (커밋 안 함, 아래 명령으로 다시 만듦) |
| 아이콘 | 128×128 PNG | `icon-128.png` |
| 스크린샷 | 1280×800 PNG, 1~4장 | `screenshot-1.png` ~ `screenshot-4.png` |
| 상세 설명 | 평문(HTML·Markdown 불가) | `description.txt` 전체 복사 |

패키지 다시 만들기(경로 구분자가 `/`가 되도록 파이썬 사용):
```bash
python -c "import zipfile,os,json; v=json.load(open('extension/manifest.json',encoding='utf-8'))['version']; z=zipfile.ZipFile(f'store/attchacha-{v}.zip','w',zipfile.ZIP_DEFLATED); [z.write(os.path.join(r,f), os.path.relpath(os.path.join(r,f),'extension').replace(os.sep,'/')) for r,_,fs in os.walk('extension') for f in fs]"
```

스크린샷 구성
1. 메인 달력: 학과 공지 마감일이 달력에 자동으로
2. 드래그 저장: 공고를 드래그해 일정으로(예시 공고는 가상의 "대학생 IT 서포터즈", 주소 example.com)
3. 날짜 상세: 원문 링크와 알림까지 한 번에
4. 알림 탭: 놓치기 전에 먼저 알려줘요

## 2. 등록 절차와 입력값
1. [웨일 스토어](https://store.whale.naver.com) 네이버 로그인 → 계정 정보 > **개발자 등록**(처음 한 번)
2. 확장앱 관리 → **새로운 확장앱 추가** → zip 업로드
3. 확장앱 정보 입력

| 칸 | 입력값 |
|---|---|
| 언어 | 한국어 |
| 앱 아이콘 | `icon-128.png` |
| 스크린샷(공통) | `screenshot-1~4.png` 순서대로 |
| 상세 설명 | `description.txt` |
| 분류 | 생산성(목록에 없으면 "도구"·"교육" 중 가까운 것) |
| 공개 설정 | 1차는 **미등록**(링크를 아는 사람만, 베타) → 피드백 반영 후 업데이트하면서 **공개** |
| 성인용 콘텐츠 | 체크 안 함 |

4. **미리보기**로 스토어 화면 확인 → **임시 저장** → **리뷰 요청**

## 3. 업데이트할 때
- `extension/manifest.json`의 `version`을 반드시 올린다(1.0.6 → 1.0.7 …). 같은 버전은 올라가지 않는다.
- 확장앱 관리 → 수정 → 수정한 패키지 업로드 → "새로운 기능" 칸에 바뀐 점(평문) → 리뷰 요청
- 심사가 끝나면 기존 사용자도 자동 업데이트된다(시점은 사용자마다 다름).

## 5. 제출 전에 사람이 확인할 것
- [ ] 아이콘·캐릭터(차차) 사용 허락: 학교 마스코트라면 홍보팀 등에 사용 승인 받기, 또는 팀이 직접 그린 캐릭터라면 그대로 사용
- [ ] 학교 API 키 사용 기간 연장(문서 기준 10/27 만료) — 만료되면 학과 공지가 갱신되지 않음
- [ ] 의견 보내기 구글폼이 로그인 없이 열리는지(시크릿 창에서 확인)
- [ ] 개인정보처리방침 페이지 열림: https://zer8m.github.io/whalecrew2/privacy.html
- [ ] 웨일에서 zip을 "압축해제된 확장앱"으로 한 번 더 설치해 6개 기능 확인
